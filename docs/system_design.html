1. Executive Summary & Core Architectural Premise

Modern software development relies heavily on automated pull request (PR) reviews to ensure code quality, security, and maintainability. Monolithic AI reviewers attempt to evaluate entire codebases in a single, unstructured LLM prompt. This approach is prone to hallucinations, misses deterministic linting and security issues, incurs high API costs, and fails to provide precise line-level feedback.

The Multi-Agent Code Review System addresses this by emulating a real-world engineering team: reviewing code through a coordinated collective of specialist agents. Highly optimized, deterministic agents handle static syntax, style, and security vulnerabilities first, providing a zero-cost, reproducible baseline. Subsequent LLM agents (Milestone 5) focus exclusively on subtle logic flaws, API contract deviations, and semantic design concerns.

3. Core Data Contracts & Communication Schemas

A decoupled multi-agent architecture requires strict, validated communication contracts. The review pipeline uses immutable Pydantic models (frozen=True) to eliminate side-effects and guarantee thread-safe concurrent execution across agents.

Finding (The Universal Currency) models/finding.py

Represents one concrete issue. Every agent outputs list[Finding], completely decoupling agents from the orchestrator and downstream report formatters.

4. Precision Line-Mapping & Diff Filtering Mechanics

Rule of Pull Request Review Hygiene: Agents must never penalize authors for pre-existing legacy code that was not modified in the PR.

The DiffParser decomposes unified diff strings into DiffFile, DiffHunk, and DiffLine models. Each DiffFile calculates a cached added_line_numbers: frozenset[int] representing every newly added or modified line in the target file.

5. Deterministic Agent Deep Dive (Milestone 3)

ASTAgent Built-in AST

Technique: ast.NodeVisitor

Checks:

• AST001: Cyclomatic complexity > 10

• AST002: Nesting depth > 4

• AST003: Function length > 50 lines

• AST004: Wildcard import *

• AST000: Syntax errors

RuffAgent Rust Subprocess

Technique: ruff check --output-format json

Capabilities:

• Fast code style & formatting checks

• Pyflakes bug risks (undefined variables)

• Parses automated fix descriptions into actionable suggestion fields

BanditAgent Security Linter

Technique: bandit -f json -q

Capabilities:

• Hardcoded credentials (B105/B106)

• Command injection via shell=True

• Unsafe execution via eval (B307)

• SQL injection vector detection (B608)
